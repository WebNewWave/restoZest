## Сильные стороны, которые видно со стороны

1. **Позиционирование выше среднего.** Ресторан сам продаёт себя через атмосферу и
   приватность, а не через «вкусно и недорого».
2. **Два продукта в одном.** С одной стороны — завтраки, бизнес-ланч, доставка. С другой —
   банкеты, свадьбы, сватовства. Это два разных клиента и два разных сценария на сайте.
3. **Средний чек 800–1500 ₽** при заявленной премиальности — то есть потенциал роста чека есть.
4. **Полное меню уже оцифровано** агрегатором доставки: 167 позиций с ценами. Готовая база
   для QR-меню и для сайта.
5. **Молодой ресторан.** По отзывам на картах — «официальное открытие совсем скоро»,
   «уже готовим, уже встречаем». Значит, сайт может стать частью запуска, а не догоняющей задачей.

Из карточки организации: банкетный зал, кофейня, летняя терраса, доставка, самовывоз,
парковка, туалет, оплата картой, Wi-Fi, кофе с собой, подарочные сертификаты.

События: свидание, корпоратив, банкет, деловая встреча, семейный ужин, свадьба, день рождения.

Открытая вакансия в постах: официанты.
